# 手机版界面来源与数据连接

`mobile.js` 与 `mobile.css` 来自之前完成的 `Lotus-Workbench/mobile/src/`，保留手机导航、稿件卡片、单主、模板、周/月历和图片组件布局。本次没有使用 React 的收纳页面，也没有新增收纳功能。

构建时把手机展示覆盖代码插入现有 `desktop/app.js` 的启动位置。两端共享同一份稿件业务逻辑、校验器和 API 客户端；只覆盖原手机版已有的展示函数。不再为手机复制另一套业务数据库或新建后端。

入口为电脑服务的 `/mobile/`。旧手机网页/原生原型的数据库不会自动上传或替换电脑记录；需要时先在原程序导出包含图片的 JSON，再在电脑端检查并确认导入。
