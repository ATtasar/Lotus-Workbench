# 电脑端 UI 来源

本目录复用用户明确指定的 `commission-workbench/接稿工作台-空白版.html`，不是 React 手机页面。

- 原 HTML SHA-256：`1f929b4808b9134354d0461a2eed640bb45fe694cc870952feb56555ccd5a3e8`。
- `styles.css` 基于该 HTML 的内嵌样式，保留黑白桌面布局；按后续需求增加画布图层控件和预览停靠样式。
- `app.js` 保留原页面渲染、表单、筛选、多选、日历联动及图片组件，后续增加本机 API、冲突保护、稿件自定义流程和单主选填资料。
- `designer.js` / `design-model.js` 为现有小票、会员卡和排版组件增加可编辑文字与图片图层、字体、底图和样式，不替换主界面。
- `model.js` 从原脚本提取原始空白数据模型和校验器，前后端共用。
- `storage.js` 通过同源 API 连接本机 SQLite 服务，默认入口为 `127.0.0.1`；可选手机联动仍以电脑数据库为准。

原 HTML、原有 React 手机源码以及 Android、云端工程保留。本地安装默认打开这里的电脑端 UI，同时保留独立的 `/mobile/` 页面。
